# Интервал значений — многопоточное ускорение

## 📋 Описание задачи

Программа генерирует 25 строк по 30 000 символов из 'a' и 'b' и для каждой
строки ищет наибольший промежуток из символов `'a'`.

Алгоритм поиска намеренно неэффективный — тройной вложенный цикл O(n³).
Менять алгоритм нельзя. Задача — ускорить программу средствами многопоточности:
каждая строка обрабатывается в отдельном потоке.

## 🎯 Цель

Отработать:
- Создание потоков через new Thread(Runnable);
- Запуск потоков через start();
- Хранение потоков в List<Thread>;
- Ожидание завершения потоков через join();
- Понимание, как многопоточность ускоряет обработку независимых данных.

## 🛠 Используемые технологии

- Java 17+
- Spring Boot
- Thread, Runnable
- List<Thread>
- Maven
